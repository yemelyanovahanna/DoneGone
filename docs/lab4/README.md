# Звіти лабораторної роботи 4

У цьому каталозі збережено загальну частину звіту та розширений звіт індивідуального завдання етапу 3.

`screenshots/` містить рисунки 25–37 і файл `Підписи.txt`. Рисунки 28 і 32 показують збережені журнали реальних повторних запусків Jest та Newman. Рисунки 35–37 документують локальні Jenkins build 5 (SUCCESS) та build 4 (навмисна помилка для перевірки блокування наступних стадій). Публікація образів у цих демонстраційних Jenkins-запусках була вимкнена.

Для нового запуску тестів див. головний README. Сирі журнали, залежності та локальні секрети до Git не додаються.

Рисунки 26–28, 30–32 і 34 перезнято. У поточну локальну базу для демонстрації перенесено два акаунти, проєкти Task1 і Task2 та їхні зв’язки з попереднього етапу. У цих проєктах не було завдань, тому до Task1 додано чотири навчальні завдання. Вихідне сховище не змінено. Паролі та дампи баз до репозиторію не додаються; Git зберігає код і звіт, а дані акаунтів залишаються в локальному Docker volume.
